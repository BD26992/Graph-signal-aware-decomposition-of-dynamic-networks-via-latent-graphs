# Diagnostics and Historical Reruns

This folder contains one-off probes, rerun scripts, MATLAB comparison helpers,
and CSV patching utilities used during development. They are kept for
provenance, but they are not the recommended public entrypoints.

Use the curated wrappers in `experiments/` for reproducible paper checks.

Some scripts in this folder assume they are run from the repository root and
may require `PYTHONPATH=.` if executed directly.
